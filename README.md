# Project Name :

🧸 Toy-Topia – A Local Kids Toy Store Platform

# Purpose :

To build an online marketplace for kids toy. Toy-Topia encourages families to discover the joy of playing by supporting local sellers and exploring top toys.

## 🌐 Project Links

- **Lives : https://toy-topia-3f784.web.app/**

## ✨ Features

- **🔑 Authentication:** Secure Login & Registration with Email/Password validation rules and Google Sign-in capabilities.
- **🛡️ Secure route validation:** Protected Routes specifically target detail cards preventing unauthorized access.
- **📱 Responsive:** Perfect both for high end desktops views and mobile interfaces.
- **📋 Profile view and updates dashboards:** Protected profile cards allow dashboard inputs edit changes directly utilizing auth contexts layouts seamlessly.
- **⚠️ 404 Route Dynamic nodes setup:** Complete fallback nodes correctly layered avoiding blank pages setups.
